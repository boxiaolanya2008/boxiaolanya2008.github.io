欢迎使用 Markdown 写文章。

## 写作方式

把 Markdown 文件放到 `posts/` 目录，再推送到 GitHub 仓库的 `main` 分支，页面会自动读取并展示。

## 侧边导航

桌面端导航固定在页面左侧，移动端通过左上角菜单按钮打开抽屉菜单。

## 支持的内容

- **加粗**、*斜体*、~~删除线~~、`行内代码`
- 列表、引用、表格、任务列表
- 代码块高亮
- 图片 `![alt](图片地址)`
- 链接 [GitHub](https://github.com/boxiaolanya2008)
